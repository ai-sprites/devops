# 发布资料与交接

通过当前可用的 Jira、文档、代码或 CI MCP 按需读取发布范围、版本、测试结果和已有发布决定，也可使用本地文件及用户提供的材料。核对实际提交、构建产物与目标环境；资料来源本身不代表发布已获授权。

手册、执行记录和证据沿用项目已有位置。没有约定时，可用 `docs/devops/<feature-id>/operations.md`；日志、监控与 CI 证据优先链接原位置。历史文档原位更新，不要求搬迁。代码、CI/CD、IaC、部署配置和构建产物保留工程目录。

交付目标版本、准备/发布/恢复的实际状态、检查结果、证据链接与剩余影响。缺少关键访问、批准、备份或验证证据时说明具体限制；未执行、未演练不能声称成功。

按任务需要把发布记录关联已有 Jira 工单，不建立跨角色资料同步流程。具体内容见 [模板与交付](../skills/sprite-devops-release/references/delivery.md)。
